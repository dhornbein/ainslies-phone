Ainslie's Phone
by Drew Hornbein

Dial:
1-9 to hear Ainslie's voice recordings
0 repeat the help message
* repeat the last recording
# enter voicemail mode
├── * repeat the last recording
├── # return to the main menu
└── 111 - 999 to hear a specific voicemail
    │   If a voicemail doesn't exist at 
    │   that number you can record one there
    ├── * start recording.
    └── # stop recording and save the message
        │   Once a message is saved, anyone 
        │   can listen to it by dialing that number
        │   After saving, you can:
        ├── * listen to the message
        ├── 1 re-record the message
        ├── 9 delete the message
        └── # return to the main menu
